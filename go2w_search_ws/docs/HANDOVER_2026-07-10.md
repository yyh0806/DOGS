## 1. 项目概述

**目标**：Unitree Go2W（轮式机器狗）+ 载荷 NX（Jetson Orin NX，6 核）跑 **FastLIO 定位 + Nav2 导航**，室内自主移动 + 房间搜索/找人。

**当前阶段**：调通"nav2 发 5 米目标，狗走过去"。**还没成功**，卡在一个性能 bug（§5）。

**硬件**：
- 狗主控（MCU）：Go2 出厂控制器，跑运动 + 残留出厂程序（会自己绕圈）
- 载荷 NX：所有重活（SLAM/Nav2/web/AI）
- MID360 激光：**物理向下倾斜 -20° 装**（狗脑袋上）
- C13 云台相机：可见光 + 红外双流
- USB 网卡：NX 连狗主控

## 2. 系统架构

### 2.1 控制权分层（关键）

```
狗主控 (MCU) —— 默认有残留程序（会绕圈），靠 NX 持续持 SDK lease 压制
   ▲ lease 一断 → 残留接管 → 狗自己绕圈
   │ unitree SDK (CycloneDDS, USB 网卡)
载荷 NX —— livox/nx_sensor/nx_motion/FastLIO/fuser/Nav2/web/bridge
   ▲ HTTP:8000 + WS:8001
PC —— 浏览器 panel + 改代码 scp 上去
```

### 2.2 NX 软件栈

| 服务 | 职责 | 备注 |
|------|------|------|
| `livox-mid360-driver` | MID360，发 `/livox/lidar`(CustomMsg 10Hz) + `/livox/imu`(200Hz) | systemd 永久 |
| `go2w-sensor` | nx_sensor：读狗 DDS → `/imu` `/odom` `/scan` + `odom→base_link` TF | systemd |
| `go2w-motion` | nx_motion：订阅 `/cmd_vel` → SDK `Move()`，**持 lease 压残留**（安全关键） | systemd |
| `go2w-web` | nx_web：HTTP:8000 + WS:8001 + AI(YOLO) + 视频 | systemd |
| `fastlio` | 定位：`/Odometry` + `camera_init→body` TF + `/Laser_map` | transient |
| `map-odom-fuser` | 算 `map→odom` TF（手写 TF 代数） | **⚠️ 296% bug（§5）** |
| `nav2-3d` | Nav2：controller(DWB)/planner(Navfn)/bt_navigator/behavior | transient |
| `pointcloud_to_laserscan` | MID360 点云 → `/scan` | launch |
| `costmap-bridge` | 独立订阅 costmap → `/tmp/costmap_lite.json`（前端展示） | 手动 |

### 2.3 导航数据流

```
MID360 → /livox/lidar + /livox/imu → FastLIO → /Odometry + camera_init→body
                                  └→ p2l → /scan
utlidar(狗自带) → nx_sensor → /scan + /odom + odom→base_link
                              ↓
            map_odom_fuser → map→odom TF  (⚠️ 卡这)
                              ↓
      Nav2 costmap (吃 /scan + TF) → planner → DWB → /cmd_vel
                                                       ↓
                                    nx_motion → SDK Move → 狗
```

### 2.4 关键文件（本机 `go2w_search_ws/`）

- `src/go2w_bridge/go2w_bridge/map_odom_fuser.py` — **296% bug 在这**
- `src/go2w_bridge/go2w_bridge/nx_sensor_node.py` — 读狗 + utlidar 方位过滤
- `src/go2w_bridge/go2w_bridge/nx_motion_node.py` — 控狗 + lease
- `src/go2w_nav/config/nav2_params_3d.yaml` — Nav2 参数
- `docker/bringup_slam_nav2.sh` — 起栈脚本（NX 上 `~/go2w_ws/`）
- `web/nx_web_server.py` + `web/costmap_bridge.py`（新）+ `web/static/{map.js,panel.html}`

### 3.2 SSH（PC 无 sshpass，用 paramiko）
```python
import paramiko
c = paramiko.SSHClient(); c.set_missing_host_key_policy(paramiko.AutoAddPolicy())
c.connect('192.168.1.104', username='nx', password='nx', timeout=8)
def run(cmd, t=30):
    si, so, se = c.exec_command(cmd, timeout=t)
    return so.read().decode('utf-8', errors='replace')
env = ('source /opt/ros/humble/setup.bash; '
       '[ -f $HOME/ws_livox/install/setup.bash ] && source $HOME/ws_livox/install/setup.bash; '
       'export RMW_IMPLEMENTATION=rmw_fastrtps_cpp ROS_DOMAIN_ID=0')
print(run(env + '; ros2 topic list'))
```

### 3.3 部署（本机改 → scp → restart）
```python
sftp = paramiko.SFTPClient.from_transport(c.get_transport())
# NX 裸 python: ~/go2w_ws/ 根 (非 colcon)

```
⚠️ NX 上 `docker/` 目录**不存在**（脚本推 `~/go2w_ws/` 根）。

## 5. 卡点（核心）

### 5.1 真凶：`map_odom_fuser.py` 296% CPU

```
PID 4105  map_odom_fuser.py  296% CPU (近 3 核)
systemd: Consumed 2h 58min CPU time   ← 跑 3h 累积 2h58m, 慢性 bug
```

**fuser 设计上 20Hz 轻量 TF 代数（<5% CPU），296% = 绝对 bug**。restart 只降到 193% = 代码 hot loop（非临时卡死）。

**这一个 bug 解释今天所有 TF 症状**：
```
fuser 296% (hot loop) → map→odom 滞后 ~2s
  ├─→ controller TF too old → 不发 /cmd_vel → 狗不动
  ├─→ costmap clearing too old → 累积堵死
  ├─→ goal_checker 用错误 pose → 假报 SUCCEEDED（狗没动）
  └─→ DWB linear.x=0（只发旋转不前进）
```

### 5.2 另一线索
```
[WARN] TF lookup 未就绪: "camera_init" does not exist
```
启动时 `camera_init` frame 还没就绪（FastLIO TF 时序晚）。若间歇缺失，fuser 20Hz lookup 重试 + TF buffer 查找开销 = 嫌疑热路径。待 py-spy 确认。

### 5.3 残留（修 fuser 后大概率自愈）
- **DWB linear.x=0**：costmap 障碍多（假载荷 >0.6 残留 + 滞后累积）→ 修 fuser + restart nav2 清累积后该好
- **TF map→base_link z=-0.3m 偏移**：z 不该有，待查

### 5.4 已排除（不是根因）
~~FastLIO 延迟~~（76% 正常）/ ~~web 抢算力~~（停 web 还 296%）/ ~~tolerance 不够~~（治标）/ ~~costmap 配置~~（正常）/ ~~低电~~（能绕圈=有电）

## 7. 教训（避免重蹈）

1. **底层优先**：狗不动先查底层（`/cmd_vel` → IMU/odom 变没），别从 nav2 反猜
2. **狗绕圈 = lease 断**：残留接管，restart motion；不行断电
3. **假成功**：goal SUCCEEDED ≠ 狗到。TF 异常下 goal_checker 误判。信 `/cmd_vel` + `/odom` + 肉眼
4. **web rclpy 加订阅就崩**（`IndexError: wait set index too big`）：costmap 用独立 bridge
5. **NX 算力有限**（6 核）：多进程互抢，top 看
6. **utlidar 扫狗自身**：脑袋/C13/载荷当假障碍，方位过滤
7. **时间同步 > tolerance**：TF 滞后别只加 tolerance，查为什么滞后

### 10.1 已完成
