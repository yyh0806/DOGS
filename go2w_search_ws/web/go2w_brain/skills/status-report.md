# 状态报告方法论

1. 依次调用三个只读工具 (顺序固定, 便于轨迹对比):
   - `get_gps` — 定位;
   - `get_battery` — 电量;
   - `get_pose` — 位姿。

2. 每个工具返回 `{"ok": false, "reason": ...}` 时, 原样报告不可用原因,
   **不要**编造数值。

3. 汇总格式 (中文, 简洁):
   - 定位: 经纬度 / HDOP / 卫星数 / 数据新鲜度;
   - 电量: SoC 百分比;
   - 位姿: x/y/yaw (无则跳过)。

4. 若 GPS 与位姿都不可用, 报告"当前无可用定位与位姿", 并提示检查
   GNSS 与定位链路 (这是 M1 验收的失败口径之一)。
